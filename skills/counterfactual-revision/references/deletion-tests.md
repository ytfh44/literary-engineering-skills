# Deletion Tests

Deletion is the cleanest test when a phrase may be redundant.

## Three questions

After deletion:

1. Which fact disappeared?
2. Which inference became unavailable?
3. Which ambiguity became harmful?

If none, the deleted material was likely commentary, repetition, or padding.

## Counterexample

Deleting `似乎` from `他似乎睡着了` changes epistemic commitment. The shortness gained is irrelevant; the proposition changed.
