# Minimal Interventions

Choose the intervention whose boundary matches the hypothesis.

| Hypothesis | Change |
|---|---|
| relation is over-explained | delete relation marker/sentence |
| verb misassigns agency | replace predicate only |
| viewpoint is misplaced | move observer/deictic center only |
| metaphor adds no specificity | remove source domain; keep facts |
| rhythm stalls | change clause boundary/order; keep lexical content |
| character voice leaks | replace register item; keep proposition |

A useful intervention produces a different reading for a reason you can name.
