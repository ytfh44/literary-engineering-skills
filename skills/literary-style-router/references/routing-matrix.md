# Routing Matrix

Use this when two skills plausibly match the same sentence.

| Collision | Choose the first when… | Choose the second when… |
| --- | --- | --- |
| narrator-intervention-abstraction-control / relation-scaffolding | the register itself sounds institutional or summary-like, or a meaning is settled before the scene earns it | the problem is repeated explicit relation scaffolding (concept-link or event-link), even in otherwise human prose |
| verb-event-engineering / chinese-derived-event-geometry | the question is role, agency, result, control, or valency in any language | Chinese packaging through serial verbs, direction/result, or coercion is the main lever |
| predicate-licensing / metaphor-audit | a noun carries a predicate its class cannot, and recovery cost is the issue | a comparison spends words without selecting a useful trait |
| camera-attention / adverb-particle-viewpoint | observation order or reveal fails regardless of grammar | a deictic/empathy/particle choice relocates the perceiver inside a language-specific construction |
| narrator-intervention / metaphor-audit | a state label closes inference | a source domain spends words without selecting a useful trait |
| property-and-adjective / narrator-intervention | a modifier's function class is in question (discriminative vs. affective) | the whole abstraction level of the narration is in question |
| naming-and-address / social-naming-relation-maps | one naming act changes the frame in one scene | the naming map and its arcs across the whole work are the structure |
| dialogue-voice / character-motive | wording exceeds the speaker's register or knowledge | behavior seems inconsistent because the inferred motive is wrong |
| dialogue-voice / knowledge-boundaries | the speaker owns the words but not the register | the character could not know or could not have learned the fact |
| counterfactual-revision / literary-evals | revise one passage and identify the causal change | test a skill, rubric, or family of outputs across cases |
| literary-strategy-controller / corpus-convergence-audit | manage the current document's state so local fixes do not become a house style | measure an existing corpus for operation-level convergence |

## Tie-breaker

Ask: **If I changed only one local variable, which variable would I touch?**

- relation marker -> relation-scaffolding
- predicate -> verb-event-engineering
- observer position/order -> camera-attention-engineering
- particle/adverb -> adverb-particle-viewpoint-engineering
- evidence object -> narrator-intervention-abstraction-control
- source domain -> metaphor-audit
- speaker ownership -> dialogue-voice
- decision rule -> character-motive
- knowledge input -> knowledge-boundaries

If no single variable is identifiable, remain in diagnosis; do not stack
skills to hide uncertainty.
