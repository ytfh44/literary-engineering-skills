# Routing Matrix

Use this when two skills plausibly match the same sentence.

| Collision | Choose the first when… | Choose the second when… |
|---|---|---|
| anti-ai-prose / relation-language-audit | register itself sounds institutional or summary-like | the problem is repeated explicit relation scaffolding, even in otherwise human prose |
| verb-engineering-core / chinese-event-geometry | the question is role, agency, result, control, or valency in any language | Chinese packaging through serial verbs, direction/result, or coercion is the main lever |
| camera-attention / language viewpoint | observation order or reveal fails regardless of grammar | a deictic/empathy/packaging choice relocates the perceiver inside a language-specific construction |
| sensory-specificity / metaphor | a state label closes inference | a source domain spends words without selecting a useful trait |
| dialogue-voice / character-motive | wording exceeds the speaker's register or knowledge | behavior seems inconsistent because the inferred motive is wrong |
| counterfactual-revision / literary-evals | revise one passage and identify the causal change | test a skill, rubric, or family of outputs across cases |

## Tie-breaker

Ask: **If I changed only one local variable, which variable would I touch?**

- relation marker -> relation audit
- predicate -> verb engineering
- observer position/order -> camera/viewpoint
- evidence object -> sensory specificity
- source domain -> metaphor
- speaker ownership -> dialogue
- decision rule -> character motive

If no single variable is identifiable, remain in diagnosis; do not stack skills to hide uncertainty.
