# Audit Order

Repair low-level causes before high-level decoration.

Default order when several mechanisms are genuinely active:

1. **Event integrity** — who does what, to whom, with what result?
2. **Viewpoint and access** — from where and in what order can the reader know it?
3. **Evidence** — what concrete event supports the state or inference?
4. **Voice** — who owns the wording?
5. **Relation language** — which explanations are now redundant?
6. **Metaphor** — does an image add object-specific information?
7. **Pressure and rhythm** — does sentence timing match information release?

Why this order: a metaphor cannot rescue a misbuilt event; a short sentence cannot rescue a misplaced observer. Later passes should not force earlier structure to move again.

Break the order only when the user asks for a single narrow operation.
