# Verbes de trajectoire

French often offers a clean main predicate when path is the event's spine:

`entrer / sortir / monter / descendre / traverser / rejoindre / quitter`

## Test

Ask what remains true if manner disappears.

`Il sortit de la pièce en trébuchant.`

Remove `en trébuchant`: the departure still occurs. Path is the backbone; manner is an added condition.

## Do not overgeneralize

Actual French usage is mixed. Lexical verbs can carry manner, and constructional choices vary by register and context. The writing skill uses a decomposition, not a typological prohibition.

## Transfer

The same test helps in English or Chinese: if path remains the scene's invariant while manner is optional, foreground path even if the target language could package manner more compactly.
