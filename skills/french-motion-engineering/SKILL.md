# French-Derived Motion Engineering

## Use when

French often makes a useful discipline visible: decide first whether the clause is chiefly about **path**, **manner**, or **appearance**, then decide where each component belongs.

## Do not use when

Do not treat French as uniformly “verb-framed,” and do not ban compact manner expressions when they are idiomatic. The typological tendency is a diagnostic, not a sentence generator.

## Core test

**Decide what the clause is about before deciding where to package it.**

If path is the backbone, a path verb may deserve the main predicate. If manner is secondary, let it remain secondary. If reveal is the event, use appearance/perception resources instead of forcing motion.

## Workflow

1. Decompose the event into **path**, **manner**, **appearance**, **observer access**, and **result**.
2. Rank those components by narrative importance.
3. In French, test whether a path verb such as `entrer`, `sortir`, `monter`, `descendre`, `traverser` should carry the spine.
4. Add manner only if it changes prediction, often through an adjunct or secondary construction.
5. If the event is visibility rather than travel, test `apercevoir`, `entrevoir`, `surgir`, `se profiler`, or another natural appearance/perception predicate.
6. If writing another language, carry the decomposition across and repack it natively. See **Transfer**.

## Minimal pair

> Il sortit de la pièce en trébuchant.

> He stumbled out of the room.

The clauses can describe the same event while allocating path and manner differently. Neither allocation is inherently more expressive; the useful question is which component each language can foreground cheaply.

## Counterexamples

- A French sentence may naturally foreground manner in the main verb; do not force every motion event into `entrer/sortir/monter`.
- An English sentence may benefit from unpacking manner into a secondary phrase when the manner should remain backgrounded.

## Transfer

French contributes a useful hierarchy test: decide whether path, manner, or appearance deserves the main predicate. That hierarchy travels better than French syntax. English may repack a secondary manner into the verb and move path to a particle; Chinese may use趋向 or a serial chain; Japanese may distribute path and viewpoint across predicates. When transfer reverses the surface allocation but preserves what is foregrounded and what is backgrounded, it has succeeded. A French-shaped target sentence is not the goal.

**Transfer the operation, not the costume.**
