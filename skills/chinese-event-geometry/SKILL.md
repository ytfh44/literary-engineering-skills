# Chinese-Derived Event Geometry

## Use when

Chinese offers unusually cheap ways to make event structure do descriptive work. Extract the operation; do not confine it to Chinese.

## Do not use when

Do not imitate classical diction, stack directional complements, or force Chinese syntax into another language. If the target language packages the same event elsewhere, use its native carrier.

## Core test

**Can the predicate make the scene more exact by changing what a noun is allowed to do, where the event goes, or what result becomes true?**

The gain must be event structure, not lexical rarity.

## Workflow

1. Write the literal event with participants and endpoint.
2. Find the load-bearing relation: sequence, path, result, orientation, or role.
3. In Chinese, test whether serial verbs, direction/result complements, or a controlled predicate crossing can carry it directly.
4. Remove explanatory adjectives or relation clauses now made redundant.
5. Check coercion cost: the reader should recover the event before noticing the unusual collocation.
6. If the target language is not Chinese, abstract the operation and repack it natively. See **Transfer**.

## Working operations

- **serialize** — let successive verbs carry event order;
- **orient** — use source/goal/deictic direction to locate motion;
- **result** — encode the endpoint in or near the predicate;
- **re-role** — let predicate choice move a noun among agent/cause/patient/result positions;
- **coerce** — grant a noun a temporary event capacity when the scene supports it;
- **eventify** — replace a static property with what the property makes happen.

## Minimal pair

> 雪很厚，阳光很刺眼。

> 视线被雪浮起一截，直撞上太阳。

The second version is not better because it is stranger. It converts snow depth into a change of perceptual geometry and sunlight into a consequence along that path. If the scene does not support those relations, the first is safer.

## Counterexamples

- `他走进来` is not automatically richer than `他进来`; if manner and path do not matter, extra event structure is waste.
- A forced predicate crossing that needs explanation after the sentence has failed its compression test.

## Transfer

Chinese is the laboratory here, not the border. First strip off Chinese morphology until only the event relation remains. For `视线被雪浮起一截`, that relation is: accumulated snow raises the visible plane and therefore the observer's effective sightline. Then ask how the target language would normally encode that causal/result geometry. English may pack it into a compact result construction; Japanese may distribute it across direction and viewpoint; French may prefer an appearance/path predicate plus a secondary phrase. If the translated clause preserves Chinese word order but loses native ease, it failed: keep the geometry, discard the calque.

**Transfer the operation, not the costume.**

Return **source operation -> event change -> Chinese carrier or target-language carrier -> calque risk**. Never conclude that the operation “cannot be done” in another language merely because the packaging differs.
