# 连动：把说明改写成路径

中文常能把“观察者怎样获得信息”压进连续动作，而不单列视点说明。

## 基本检查

把句子拆成：

`动作 A -> 位置/姿态变化 -> 动作 B -> 新可见事实`

若每一步都改变下一步的可达信息，连动在工作。

例：

`推门出去，绕过井台，才看见墙根那辆自行车。`

这里不是三个同义动作堆叠。前两个动作逐步解除遮挡，最后一个感知才成立。

## 失败

`他走过去，来到门边，靠近门口，看向门外。`

若四个谓词只重复“接近”，连动没有增加事件几何。

## 可迁移操作

其他语言不必复制无连接词的连动形式。保留的是**行动链承担视点移动**：让观察条件由动作产生，而非旁白宣布“视角转向”。
