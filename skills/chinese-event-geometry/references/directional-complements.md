# 趋向补语：方向也是视点预算

`来 / 去 / 上 / 下 / 进 / 出 / 回 / 过 / 起` 及复合趋向可以同时携带路径、终点和说话/叙事中心。

## 三个问题

1. 物体实际向哪里运动？
2. 哪个点被当作“这里”？
3. 换 `来/去` 后，读者是否被迫站到别处？

`拿过来` 与 `拿过去` 的物理动作可能相似，但叙事中心不同。

## 不要把每个趋向都文学化

`想起来 / 看起来 / 说下去` 等已经发生语法化或语义扩展。先判断它在当前句中承担的是空间、体貌、结果还是话语功能。

## 跨语言迁移

迁移的不是 `来/去` 字面，而是**给运动指定一个叙事中心**。目标语言可能用 come/go、venir/aller、視点一致性、句序或省略完成同一工作。
