# False Depth

False depth often appears as a relation-shaped sentence whose symmetry substitutes for discovery.

Watch for forms such as:

- 不是 A，而是 B
- 并非 X，而是更深层的 Y
- 某种意义上
- 真正的……从来不是……
- 他终于明白……

None is guilty by form. Test the **delta** between A and B.

## Delta test

If B is only a more abstract restatement of A, the contrast is decorative.

> 他不是生气，而是在用愤怒保护自己。

Possible failure: “愤怒” is repackaged as a therapeutic relation without new scene evidence.

> 他不是没听见。他在等第二遍。

Here B changes the event model. The contrast earns the hinge.

## Rule

A reversal should change prediction. If the reader would expect the same next action after both halves, the sentence may be staging depth rather than adding it.
