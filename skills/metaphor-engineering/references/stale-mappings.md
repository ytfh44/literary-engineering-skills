# Stale Mappings

A stale mapping is not simply a familiar phrase. It is a mapping whose transferred information has collapsed to one generic property.

Common collapsed pairs:

- anger -> fire
- sadness -> rain
- darkness -> ink
- crowd -> sea
- silence -> blanket
- eyes -> stars

Do not ban them. Ask what the source contributes **in this sentence**.

> 人群像潮水一样退开。

If the crowd withdraws in a coordinated front around an obstacle, “tide” may encode shape and motion. If it only means “many people,” it does not.

## Anti-novelty warning

An exotic source can be worse because it forces the reader to learn the source before seeing the target. Precision is the criterion; surprise is incidental.
