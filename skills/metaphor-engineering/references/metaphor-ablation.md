# Metaphor Ablation

Test an image by deleting only the source domain.

## Procedure

1. Write the literal fact beneath the metaphor.
2. Delete the comparison.
3. List lost information.
4. Restore only the lost information that matters.

Example:

A: `阳光像刀一样刺眼。`

Literal remainder: `阳光很刺眼。`

Lost information: perhaps narrowness, cutting edge, sudden contact. If none is used later, `刀` may be surplus.

Contrast:

A: `百叶窗把阳光切成一排窄刀。`

Delete “刀” and the strip shape remains partly recoverable, but the repeated narrow cutting relation may still justify the source.

Ablation cannot tell you that a sentence is beautiful. It can tell you what the metaphor actually carries.
