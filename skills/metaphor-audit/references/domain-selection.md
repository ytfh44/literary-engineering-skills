# Domain Selection

Choose a source domain because its internal relations match the target, not because its mood matches the scene.

## Bad selection question

“What image feels sad?”

## Better selection questions

- What moves the same way?
- What leaves the same residue?
- What resists in the same place?
- What changes scale the same way?
- What misleads the observer in the same way?

## Example

Target: frost on a window that thickens from the edges inward.

Weak source: “white lace” — mostly shared appearance.

Stronger source: a map being erased from its borders — carries direction, loss of detail, and encroachment.

The source is useful because it predicts the change, not because “map” is rarer.
