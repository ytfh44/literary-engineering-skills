# 关系句式

## 高风险不是高罪率

这些结构容易被模型用来自动组织“意义”：

- `不是 A，而是 B`
- `正因为 A，所以 B`
- `随着 A，B 也……`
- `在某种意义上……`
- `这意味着……`
- `从 X 到 Y，不仅……更……`

检查的是结构功能，不是表面形式。

## 一变量最小对照

原句：`他笑了。这意味着他已经原谅我。`

删关系句：`他笑了。`

若后文依赖“已经原谅”这一事实，而笑本身无法保证它，原句有信息；若后文只让人物继续吃饭，第二句可能是作者结算。

## 关系可以交给什么承载

- 事件顺序：先因后果
- 谓词选择：`撞碎` 已含结果
- 主宾安排：谁被置于受事位置
- 视点：谁先看见什么
- 重复：同一动作第三次出现
- 省略：不解释本身可以保留不确定性

不要为了“少虚词”硬把关系藏起来。只有在替代载体更便宜、更准时才迁移。
