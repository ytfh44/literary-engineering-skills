# Function-Class Tests for Adjectives

## The test battery

For every modifier, run the class test before any verdict.

**Discriminative test.** Would reference survive deletion? If two possible
referents remain and the modifier separated them, it is discriminative;
deleting it breaks the scene's identification. If only one referent was
possible, the discriminative load is zero.

**State-bearing test.** Does the modifier report a checkable condition?
"湿衣服" can be verified by touch; "冷" can be verified by temperature. If
the condition matters to a later event (wet clothes -> shivering -> illness),
deleting it removes a causal fact. If no event consumes the condition, the
state is available — trim or eventify, do not ban.

**Evaluative test.** Whose judgment is this? The modifier may carry the
narrator's position, a character's perception, or an institution's framing
("不配合的病人"). Deleting it deletes the judge. If the judge is a present
character, the adjective is evidence about them; if the judge is the author
invisibly, the adjective is a verdict the scene has not earned.

**Affective test.** What does the modifier do to the emotional field? It
may change nothing factual and still be the only carrier of the scene's
temperature. Test: if the paragraph loses its atmosphere when the modifier
is gone and no other mechanism supplies it, the affective load is real.

## The redundancy check

A modifier can be deleted when its loss is already carried elsewhere:

- the state is already in the event (窗开着 -> 冷风灌进来 makes 冷 redundant);
- the judgment is already in the dialogue or action;
- the reference is already established by the camera or by prior mention;
- the affect is already in the rhythm, the metaphor, or the scene's
  temperature.

Redundancy is the only count-based signal, and it is checked per modifier,
not per passage.

## Minimal pair

> 他推开门，寒冷的北风灌了进来。
>
> 他推开门，北风灌了进来。

The first names the cold the second lets the wind carry. If the story needs
the reader to feel cold now (affective), the first is doing its job. If the
story only needs the door event, 寒冷 was redundant with the wind.

> 她看了一眼窗外灰蒙蒙的天。
>
> 她看了一眼窗外。

If "灰蒙蒙" tells us why she stays home (state -> decision), keep. If
nothing downstream consumes the weather, it is available decoration.

## Counterexamples

- In a deliberately flat narrator's voice, adjectives are sparse on
  purpose; the flatness is the voice. Do not add color, and do not trim the
  few adjectives that are doing discrimination.
- A character who thinks in judgments ("这个蠢货经理") — evaluative
  adjectives are the character's grammar; replacing them with neutrality
  destroys the voice.
