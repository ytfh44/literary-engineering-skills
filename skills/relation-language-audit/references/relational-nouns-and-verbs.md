# 关系实词：不是词性问题，是结算问题

关系实词把一组事件结算成一个抽象变量。常见如：

`关系 / 状态 / 过程 / 变化 / 层面 / 维度 / 意义 / 影响 / 体现 / 意味 / 反映 / 形成 / 导致`

它们在论文里常是必要的；在小说里最容易抢走场景的工作。

## 检查法

把句子改写成问题：**它究竟结算了哪些可观察事件？**

> “两人的关系发生了变化。”

可能结算：不再共用钥匙、称呼改变、账单分开、坐得更远。若正文已经给出这些，抽象句可能重复；若要跨过三年时间，它反而很便宜。

## 不是“具体词优于抽象词”

> “她的婚姻结束了。”

这是一个高信息密度的抽象结论，可能比十个搬箱子的动作更准确。

真正的判据：**抽象词是否新增压缩后的事实，还是只替读者念答案。**
