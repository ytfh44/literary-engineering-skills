# 中文虚词：统计只负责报警

这里的“虚词”按写作检查使用，不追求学校语法分类的完整一致。

## 四类高收益检查

### 1. 因果
`因此 / 所以 / 于是 / 从而 / 因而`

问：因果是否已经由相邻事件唯一地恢复？

- `没锁窗，所以雨进来了`：若只是叙事，可试删。
- `因为第二个样本污染，所以该结论不能外推`：因果是论证骨架，保留。

### 2. 转折与校正
`然而 / 但是 / 却 / 反而 / 并非……而是……`

问：转折改变预测，还是只把一句普通话摆成“有深度”的姿势？

### 3. 同时与层次
`同时 / 与此同时 / 另一方面 / 更进一步`

问：时间或论证层次是否真的需要显式同步？如果两个动作天然并行，重复标注会让场景像会议纪要。

### 4. 模糊与认识状态
`似乎 / 仿佛 / 大概 / 某种`

这类词常常必须保留，因为它们改变的是认识论，不是装饰。

## 留词测试

一个虚词至少应承担一项：

- 排除另一种因果；
- 标明时间顺序；
- 改变命题强度；
- 限定说话者确信程度；
- 组织复杂论证；
- 构成人物口吻。

若一项都没有，再删。
