# 古典最小例：看动词怎样造事件

这些例子用于拆机制，不用于规定现代文风。

## 春风又绿江南岸

`绿` 原本常作颜色/性质，在句中被动词化：春风不是“让江南岸呈绿色”之后再说明，而是直接把“变绿”压成事件。

操作：**性质 -> 变化谓词**。

迁移：别的语言可用 inchoative/causative verb、resultative 或派生结构实现，不必复制词类活用表面。

## 行到水穷处，坐看云起时

`行 -> 到 -> 坐 -> 看` 让观察位置由动作产生。诗句的视场不是先给定再描写。

操作：**运动建立观察条件**。

迁移：目标语言可以用 clause chain、participial phrase、motion verb、deictic marker 等承载。

## 奔马毙犬

相较于强调“杀者”的表达，`毙` 更把事件结算在结果端。

操作：**换谓词，改事件角色与道德承诺**。
