# Knowledge Boundary vs Voice Boundary

Two different errors are often collapsed.

## Knowledge error

The character possesses information they could not have acquired.

## Voice error

The character could know the fact but expresses it in a register not available or not natural to them in this situation.

Example:

A middle-school student can correctly infer that a buyer will return a kitten if its temperament is misdescribed. He need not think in terms such as “reducing post-transaction mismatch.”

## Test

Ask separately:

1. Could this person know it?
2. Would this person package it this way now?

Do not use one answer to decide the other.
