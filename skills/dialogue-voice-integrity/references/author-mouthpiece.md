# Author Mouthpiece

A single sophisticated sentence is not the main warning. Repeated **shared abstraction** across unrelated characters is.

## Audit

Collect lines from three speakers and remove names. Look for identical habits:

- same concessive frame;
- same relationship nouns;
- same moral summaries;
- same metaphor domains;
- same sentence-final insight.

If voices collapse, do not manufacture accents first. Restore different **attention and motive**:

- what each notices;
- what each wants from the listener;
- what each refuses to name;
- which nouns each uses as evidence.

Voice diversity grows from unequal world models, not spelling quirks.
