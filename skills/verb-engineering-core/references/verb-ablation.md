# Verb Ablation

Change one predicate and hold the rest still.

## Procedure

1. Copy the sentence.
2. Replace only the target verb.
3. For each version, list: role assignment, result, manner, duration, control, viewpoint.
4. Keep a replacement only if at least one narratively relevant dimension changes.

## Example

`雨落在铁皮上。`

`雨敲在铁皮上。`

The second grants impact/rhythm and lightly personifies agency. If the next sentence depends on repeated audible impacts, it earns the change. If not, `敲` may merely advertise itself.

## Anti-pattern

Do not generate ten synonyms and choose the rarest. A lexical menu hides the event question.
