# Grading Rubrics

Grade causal understanding before surface polish.

## Core dimensions

- **Mechanism**: names the actual variable.
- **Evidence**: quotes the smallest relevant span.
- **Intervention**: changes only what the hypothesis requires.
- **Counterexample control**: spares a necessary suspicious form.
- **Voice preservation**: does not overwrite the author's register merely to satisfy the skill.
- **Transfer**: carries the operation across languages through native resources.
- **Anti-template**: avoids repeating a house phrase across unrelated outputs.

Use `pass / partial / fail` with one reason. A precise failure reason is more useful than a 7.3/10.
