# Multilingual Regression

Language-named skills are source traditions, not exclusive territories.

Test two errors separately:

1. **exclusivity error** — “this mechanism belongs exclusively to its source language”;
2. **calque error** — transferring the source language's surface form instead of the operation.

## Transfer case pattern

- Name source mechanism.
- Restate it language-neutrally.
- Ask for a target-language realization.
- Grade whether the target uses a native carrier.

Example: Japanese attention-state vocabulary may motivate an English revision that changes clause timing or perception verb, not an imitation Japanese adverb.

Core rule: **transfer the operation, not the costume.**
