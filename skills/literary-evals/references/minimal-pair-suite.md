# Minimal Pair Suite

A minimal pair changes one variable whose effect the skill claims to understand.

## Good pair

A: `她显得很不耐烦。`

B: `她第三次看表。`

Use only if the tested rule is “state label vs evidence.” Do not also change viewpoint, tense, metaphor, and register.

## Bad pair

A plain sentence versus a rewritten paragraph with different facts, imagery, rhythm, and point of view. Even if B is better, the test cannot say why.

## Pair checklist

- same factual event where possible;
- one targeted structural change;
- predicted effect stated before grading;
- at least one reversal case where the preferred side should switch.
