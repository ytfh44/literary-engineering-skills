# 状态名与证据

状态名直接结算：`烦 / 怕 / 累 / 尴尬 / 冷`。
证据提供局部事实：`第三次看表 / 锁门两遍 / 鞋没脱就坐下 / 把杯子挪远`。

两者没有高下，只有成本不同。

## 用状态名

- 状态本身是新信息；
- 节奏要求迅速结算；
- 说话人自然会这样命名；
- 继续铺证据只会重复已知内容。

## 用证据

- 状态需要保留歧义；
- 读者还应自己判断原因；
- 一个动作同时暴露时间、关系或环境信息；
- 作者式心理分类会越过当前视点。

## 失败例

`她皱眉，握拳，呼吸一滞。`

三个“可见细节”可能仍然只是库存式情绪编码，没有人物特异性，也没有新的事件。
