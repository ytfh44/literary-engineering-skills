# 古典视点例：视野如何被打开

## 山部赤人《万叶集》318（常见校读）

`田子の浦ゆ　うち出でて見れば　真白にそ　富士の高嶺に　雪は降りける`

这里可拆为一个观察路径：

`ゆ`（经由/从该处移动） -> `うち出でて`（从遮挡或内部走出） -> `見れば`（建立观察） -> `ける`（在传统解释中常带发现/感叹色彩）。

重点不是把每个助词神秘化，而是：**观察者先移动，视野随后成立。**

后世百人一首常见版本：

`田子の浦に　うち出でて見れば　白妙の　富士の高嶺に　雪は降りつつ`

`に` 与 `つつ` 的组合让读法更容易落到一个较稳定的观察位置和持续景象。具体文法史可有细分；写作上可把二者当作视场组织的最小对照。

## 可迁移操作

不是“用日语助词”。而是：

`移动观察者 -> 解除遮挡 -> 建立视觉 -> 让发现时态/体貌落地`

中文、英语、法语都可以用自己的谓词和句序重建这一条路径。
