# The Contrast Trap

A pasted contrast has this shape:

`negative label + one conventionally tender exception`

Examples: killer + feeds cats; tyrant + loves children; thief + gives to charity.

The exception often functions as moral coupon rather than causal information.

## Test

Ask what variable selects the exception.

- If the answer is “to show he has a soft side,” the contrast is authorial.
- If the answer is a stable rule — kinship, debt, craft pride, category boundary, status — the behavior may be generated.

## Reverse use

Contrast can also remove cheap redemption. A person may behave generously toward friends yet reveal a narrow moral domain elsewhere. The point is not darkness; it is to stop one good action from licensing virtues the character never had.
