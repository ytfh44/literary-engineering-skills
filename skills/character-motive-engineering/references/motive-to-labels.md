# From Motive to Labels

Do not start with `kind / cruel / proud / shy / loyal`. Start with a decision rule.

## Example generator

`Never let a named debt remain open.`

Possible outputs:

- repays a tiny loan immediately;
- remembers a favor for years;
- refuses vague “you owe me one” arrangements;
- accepts an expensive loss to settle a precise obligation.

Readers may call the character generous, petty, loyal, obsessive, or honorable. None is the generator.

## Diagnostic

If deleting the trait label makes it impossible to predict any action, the character sheet has description but little mechanism.
