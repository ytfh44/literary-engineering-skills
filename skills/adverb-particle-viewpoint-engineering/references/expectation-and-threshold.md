# Expectation and Threshold: the Discourse-Function Inventory

## Why functions, not words

The same carrier word maps to different discourse functions in different
contexts, and different carriers can serve the same function. Analysis must
name the function first: 才 is not "a 才 problem," it is a threshold
problem.

## The inventory

- **Recurrence** — the event has a prior occurrence (又, again, wieder,
  また). The reader must recover the earlier instance; the recurrence is
  the information.
- **Delayed threshold** — the event arrives against an expectation of
  earliness (才, only-now, erst). The stance: "this should have happened
  sooner."
- **Restriction** — an alternative set is excluded (只, 仅, only, nur).
  The stance: "nothing else."
- **Violated expectation** — the event contradicts the predicted
  alternative (竟然, 竟, surprisingly, tatsächlich in some uses). The
  stance: "this was not in the model."
- **Addition** — the event joins an accumulating set (还, 也, also, noch).
  The stance: "on top of what was already true."
- **Unplanned onset** — attention arrives without prior intention (忽然,
  ふと, unawares). Distinct from suddenness: the variable is intention,
  not speed.
- **Sustained vs. sampled attention** — じっと vs. ちらり, 一直 vs. 一瞥.
  The stance is the duration and commitment of the look.
- **Epistemic hedge** — 似乎, 好像, maybe. The stance: the perceiver's
  certainty, not the event's probability.

## Context tests

For each candidate, run:

1. **Prior-occurrence test** (recurrence): would the sentence be wrong if
   this is the first occurrence? If yes, the function is recurrence and the
   prior instance must be recoverable nearby.
2. **Expectation test** (threshold): against whose expectation is the event
   late or early? If no expectation exists in the context, the threshold
   reading collapses and the particle is doing something else.
3. **Alternative-set test** (restriction/addition): what set does the event
   join or exclude? If the set is not recoverable, the carrier is noise.
4. **Prediction test** (violation): who predicted the alternative that the
   event contradicts? If nobody predicted anything, 竟然 overclaims.
5. **Intention test** (unplanned onset): was there a prior intention to
   look? If the perception was deliberate, ふと/忽然 is a factual error.

## Transfer, not translation

Carriers do not translate one-to-one:

- recurrence may live in a verb prefix (German be-/wieder-), an aspect
  marker, an adverb, or clause order;
- threshold may live in a temporal construction (not until…), a particle,
  or word order;
- unplanned onset may live in a perception verb choice (happen to look,
  抬眼) rather than any adverb.

The transfer succeeds when the reader's stance — not the surface word —
survives. Literal resemblance is optional; stance equivalence is not.

## Counterexamples

- 才 in dialectal speech can mark simple emphasis with no threshold
  content; the function inventory must be applied to the actual register.
- A deliberately monotonous narrator may strip all stance carriers as a
  voice choice; the flatness is the voice, not a defect to fix.
- Ritual or incantatory prose may use particles for rhythm, not discourse
  function; audit rhythm axes before discourse axes.
