# Adverb-Particle-Viewpoint Engineering

## Use when

The objective event stays constant, but a small word changes how the event
is presupposed, attended to, expected, or located. This layer governs the
reader's stance — and it is the layer where hard rules fail fastest.

## Do not use when

Do not apply shallow rules here: no "high-frequency adverbs -> delete," no
cross-language surface mapping ("Japanese uses adverbs, English uses
prepositions, Chinese uses…"). These claims collapse on the first real
sentence. If the question is about grammatical deictic or empathy choices
inside a specific language tradition, the Japanese viewpoint references
under `references/japanese-viewpoint/` are a laboratory, not a law.

## Core test

**Keep the event constant. Change one carrier. If the reader now stands
somewhere else, the carrier is doing narrative work.**

> 他看了窗外。
> 他又看了窗外。     — recurrence: this happened before, again
> 他才看了窗外。     — delayed threshold: he should have looked earlier
> 他只看了窗外。     — restriction: nothing else got his attention
> 他竟看了窗外。     — violated expectation: this was not predicted
> 他还看了窗外。     — addition: on top of everything else
> 他忽然看了窗外。   — unplanned onset of attention

The event (he looks out the window) never changes. The discourse world
does.

## Working operations

- **recurrence** — 又: the event has a prior occurrence the reader must
  recover;
- **threshold** — 才: the event arrived late against an expectation;
- **restriction** — 只/仅: an alternative set was excluded;
- **violation** — 竟然/竟: the event contradicts the predicted alternative;
- **addition** — 还/也: the event joins an accumulating set;
- **unplanned attention** — 忽然/ふと: the perception has no prior
  intention (see the Japanese tradition);
- **sustained attention** — じっと/一直: the perception is locked;
- **sample attention** — ちらり/一瞥: the perception is brief and
  noncommittal.

## The minimal-pair protocol

1. Write the objective event in plain terms.
2. Freeze every other variable (word order, register, length).
3. Change exactly one carrier.
4. Read the new stance: what presupposition, expectation, alternative set,
   or empathy center appeared?
5. Name the discourse function, not the word: 才 is not "a 才 problem";
   it is a threshold problem.
6. For transfer: ask how the target language expresses the same discourse
   function natively. 又's recurrence may live in a verb, a prefix, an
   aspect marker, or an adverb — the function travels, the carrier does
   not.

## Rule strength

**Minimal pairs + language-specific interpretation — the lowest in the
pack.** No universal preferences, no blacklists, no automatic rewrites.
Every claim here is a hypothesis about stance, verified by one-variable
intervention in the specific language, dialect, and register. Counterexample
weight is at its maximum: the same particle can carry different discourse
functions in different regions and registers, and no function is inherently
better than another.

## Minimal pair

> 他又来了。
>
> 他才来了。
>
> 他也来了。
>
> 他竟然来了。

Four stances from four particles: recurrence, delayed arrival against
expectation, addition to a set, and violated prediction. If the scene's
information is "this visit was not predicted," 竟然 is the exact carrier and
又 is a factual error. If the scene's information is "this visit repeats a
pattern," 又 is exact and 竟然 overclaims.

## Counterexamples

- Adding 又 to every recurrence does not create rhythm; it creates a tic.
  One-variable tests are for diagnosis, not for installation.
- English "suddenly" is not a translation of ふと: sudden event onset and
  unplanned attention are different variables, and conflating them is
  exactly the kind of shallow cross-language mapping this skill rejects.
- 才 in 他才来 can be threshold-relative to the speaker's expectation, not
  an absolute judgment; the function is context-shaped.

## Return shape

Return **objective event -> changed carrier -> discourse function -> reader
stance -> transfer carrier (if asked)**. Never return "delete this adverb"
or "add this particle" without naming the stance it creates or removes.
