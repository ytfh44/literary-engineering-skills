# Camera and Attention Engineering

## Use when

The scene fails because the reader does not know **where to look next**, not because the nouns are weak.

## Do not use when

Do not turn prose into screenplay directions. Camera is a discourse model: it tracks access to information, not literal lenses. For grammatical deictic or empathy choices, use the relevant language-named viewpoint skill.

## Core test

**Strip rare words, metaphor, and emotion labels. If the scene still advances because each new look is well chosen, the camera works.**

## Workflow

1. Mark the observer’s current location and what is occluded.
2. Mark the first object available to perception.
3. For each next sentence, name the transition: move, turn, reveal, zoom, track, infer, or act.
4. Check continuity. A new object must be reachable from the previous attention state unless the cut is deliberate.
5. Reorder only when the new order changes suspense, scale, causality, or recognition.
6. Let action replace viewing when the observer enters the scene physically.

## Operations

- **reveal** — remove an obstruction or cross a threshold;
- **scale** — whole -> part or part -> whole;
- **track** — follow one moving object;
- **handoff** — one object directs attention to another;
- **reverse** — the observed thing turns back on the observer;
- **freeze** — hold the frame while one variable changes;
- **cut** — break continuity on purpose.

## Minimal pair

A: `院里有树，树下有猫，门口停着一辆车。`

B: `他推门，看见树下那只猫。猫一窜，钻进门口那辆车底。`

The nouns barely change. B gives attention a path: threshold -> cat -> motion -> car.

## Counterexamples

- A static inventory can be right when the narrator is deliberately cataloguing a room or evidence table.
- A hard cut can be stronger than continuous tracking when the story wants disorientation or temporal shock.

## Return shape

Return **current field -> attention transition -> newly available fact -> continuity verdict**. When revising, change order before changing diction.
