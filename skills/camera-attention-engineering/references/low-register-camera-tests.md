# Low-Register Camera Test

Remove the usual prestige signals:

- no rare adjectives;
- no decorative metaphor;
- no abstract emotion labels;
- common verbs only where possible.

Then ask whether the observation order still works.

A useful test sentence can be almost childish:

`湖里有荷花。荷花上有只蛤蟆。手一戳，它蹦了。`

The point is not literary merit or authorship. The sequence still has scale reduction and a perception-to-action switch.

If a scene collapses without ornamental vocabulary, the ornament may have been hiding a weak attention path.
