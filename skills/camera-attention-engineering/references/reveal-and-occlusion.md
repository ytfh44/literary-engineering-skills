# Reveal and Occlusion

A reveal is stronger when the text specifies **why the object becomes visible**.

Cheap carriers include:

- opening a door/window;
- rounding a corner;
- climbing above an obstruction;
- light reaching a surface;
- another object moving aside;
- sound directing sight before the object appears.

## Minimal pair

`前面是一座塔。`

`走出竹林，塔尖先从坡后露出来。`

The second does not merely add detail. It gives visibility a cause and a partial order.

## Failure mode

Do not force every description through a reveal mechanism. Sometimes the object is already there and immediately available; manufacturing an obstruction only delays the sentence.
