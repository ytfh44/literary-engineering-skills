# Scale and Distance

Scale changes should have a reason.

Common useful paths:

- wide scene -> moving anomaly -> identifying detail;
- detail -> object -> surrounding consequence;
- distant silhouette -> geometry -> material;
- body -> hand -> object acted upon.

## Test

At each scale change, ask what question the previous scale raised.

If no question leads to the next scale, the sequence may be a catalogue rather than a visual path.

## Example

`远处堤坝一线发白。再近些，白的是漫过坝顶的水。水里还浮着一排护栏尖。`

Each step resolves the previous ambiguity and introduces the next.
